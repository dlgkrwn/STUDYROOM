# 글로벌기업 데이터 시각화 (R · Tableau)

2022년 Forbes 기준 **글로벌 기업 순위·시장가치·국가별 분포를 시각화**해 세계 시장 흐름을 한눈에 파악한 프로젝트.

- **분야:** 데이터 시각화 · 탐색적 분석(EDA)
- **팀:** 3인 (최은정, 박지윤, 이학주)
- **내 역할:** **전처리·시각화 등 전 과정 참여**

## 주제 · 목표
- 주제: 2022 글로벌 기업(수 개국에 걸쳐 영업하는 다국적 기업) 데이터.
- 목표: 최신(2022.05) 글로벌 기업 순위와 시장가치를 시각화해 시장 흐름·트렌드를 파악.

## 시각화 내용
- **워드클라우드**로 글로벌 기업 순위 표현(1위 Berkshire Hathaway, 2위 ICBC 등).
- **국가별 글로벌 기업 수**(미국 590 · 중국 297 · 한국 65 등) — Tableau.
- 국가별 매상 비율(1위 미국·2위 중국·3위 일본).
- 상위 7개 기업 **시장가치 막대그래프**(시장가치 기준 재정렬 비교).

## 도구
R(시각화·워드클라우드), Tableau.

## 파일
- `시각화_과제.R` — R 시각화 스크립트.
- `tableau/` — Tableau 워크북(`.twb`).
- `발표자료.pptx`

> `.twb`는 Tableau/Tableau Public에서 열립니다.
