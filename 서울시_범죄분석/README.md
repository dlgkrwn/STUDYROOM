# 범죄도시 서울?! 안전도시 서울로! — 서울시 자치구별 범죄 발생 분석

서울시 자치구별 범죄 발생 현황을 분석해 **안전 취약 지역을 찾고 도시 안전 정책(CPTED) 방향을 제언**한 데이터 분석·시각화 프로젝트.

- **분야:** 데이터 분석 · 탐색적 분석(EDA) · 데이터 시각화(Tableau)
- **유형:** 데이터분석스쿨 미드 프로젝트 (2조, 6인)
- **내 역할:** 기획서 작성 + **지역환경적 요인(대중교통) 분석 및 시각화**

## 배경
- 묻지마 범죄 증가 등 도시 안전 문제 대두. 서울시민 안전 인식 조사에서 '범죄'가 불안 항목 상위(4위).
- 자치구 간 범죄 발생 차이를 객관적 데이터로 분석해 정책 수립의 근거를 마련.

## 분석 관점 (범죄 발생 영향 요인)
- **지역환경적 요인:** 범죄 발생 장소·시간, 대중교통 이용량
- **범죄 감시 요인:** CCTV 개수, 경찰서 수
- **인구구성적 요인:** 1인 가구 수, 인구밀도

## 주요 결과
- **장소:** 노상(길거리)에서 범죄가 압도적으로 최다(약 29,320건).
- **범죄 유형:** 5대 범죄 중 폭력(46,783건)·절도(37,579건)가 다수, 강도·살인은 저빈도.
- **시간대:** 절도·폭력은 시간대와 무관하게 상시 다발, 강도·살인은 전반적으로 낮음.
- → 노상에서 발생하는 폭력이 핵심 취약 지점으로 확인.

## 기대효과
1. 도시 안전성 평가
2. 범죄 예방·대응 전략 및 정책 마련(대상: 서울시 범죄예방 부서/경찰청 담당)
3. 취약 자치구 파악 → **CPTED(범죄예방 환경설계) 계획 방향 제시**

## 도구
Tableau(시각화), 공공데이터 전처리.
