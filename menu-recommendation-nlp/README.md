# 메뉴 추천 서비스 (한국어 NLP)

외식 물가 상승으로 집밥(홈쿡) 수요가 늘어나는 흐름에 착안해, **레시피 데이터를 자연어처리로 분석하고 메뉴를 추천**하는 프로젝트.

- **분야:** NLP(한국어) · 텍스트 전처리 · 형태소 분석
- **팀:** 3인 (손병민, 문가빈, 이학주)
- **내 역할:** **데이터 불용어 제거 & 정규화(텍스트 전처리)** + 발표

## 배경
- 외식 물가 부담 증가로 '홈쿡족'·'냉장고 파먹기' 등 집에서 해 먹는 수요 증가.
- 가진 재료·상황에 맞는 메뉴를 추천해주는 서비스의 필요성.

## 내용
- 데이터: 레시피 검색 데이터(`TB_RECIPE_SEARCH`) — 요리명·상황·재료·종류 등.
- 전처리: **KoNLPy(Okt) 형태소 분석**, 불용어 제거·정규화, 토큰화.
- 모델링: 특징 벡터화 + 예측/추천(scikit-learn 등).

## 파일
- `NLP_(2).ipynb`, `NLP (3).ipynb`, `NLP (4).ipynb` — 단계별 작업 노트북.
- `발표자료.pdf`
