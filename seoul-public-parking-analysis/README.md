# 서울시 공영주차장 분석 (비정형 데이터 분석)

공공데이터를 활용해 **서울시 공영주차장의 위치와 주차구획 현황을 분석·시각화**하고, R Shiny 애플리케이션으로 구현한 프로젝트.

- **분야:** 비정형 데이터 분석 · 공공데이터 · 데이터 시각화 · R Shiny
- **팀:** 4인 (김재혁, 강남일, 손병민, 이학주)
- **내 역할:** **전처리 · 시각화**

## 배경
- 서울시 불법 주·정차 위반 건수가 매년 증가하는 추세.
- 공영주차장의 위치·주차구획 수를 파악해 주차 문제 완화에 참고할 정보를 제공.

## 데이터 (공공데이터포털)
- **전국주차장정보 표준데이터**(변수 31개): 주차장명·구분(공영/민영)·유형(노상/노외/부설)·주소·주차구획수·급지·요금·결제방법·위경도 등.
- **서울시 행정동별 자동차 등록대수 현황**(변수 16개): 시군구·행정동·연료·용도별 대수 등.

## 방법
- 데이터 수집·전처리, 주차장 위치·구획 수 분석, 지도/차트 시각화, **R Shiny 앱**으로 배포.
