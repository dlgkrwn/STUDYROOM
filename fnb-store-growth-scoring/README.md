# AI 기반 성장 유망 매장 스코어링 (산학 캡스톤)

외식업(F&B) 매장의 공개·상권·리뷰·기업 데이터를 결합해, **현재 가치는 낮지만 미래 성장 잠재력이 높은 "투자 검토 후보" 매장을 선별**하는 AI 스코어링 모델. 기업 **르몽**과 함께 진행한 산학 협력 프로젝트.

- **분야:** 데이터 엔지니어링 · 응용 ML · NLP(리뷰) · 시계열
- **유형:** 산학 캡스톤 (팀 "비전몽")
- **내 역할:** _(담당 파트 기입 — 예: 데이터 파이프라인 / 피처엔지니어링 / 모델링 등)_

## 🔒 데이터·보안 고지 (중요)
본 프로젝트는 기업 **르몽과의 산학 협약(NDA)** 하에 진행되었습니다. 기업이 제공한 **원본 데이터(주문·매출·리뷰 등)와 일부 세부 구현·성능 수치는 보안상 공개할 수 없습니다.** 따라서 이 저장소에는 **공개 가능한 방법론과 발표자료 중심의 내용만** 담았으며, 원본 데이터·기업 내부 산출물은 포함되어 있지 않습니다.

## 개요
- **목표:** 기업 고객 DB를 활용해 투자 검토 후보를 선별 → 솔루션 도입으로 매장 성장 지원 → 순환 구조 형성.
- **접근 가설:** ①리뷰·주문·매출 흐름의 성장 신호 ②고객 만족·재방문 누적 ③운영 대응(사장님 답글) 역량 ④외부 평판·상권 교차검증.
- **데이터:** (공개) 소상공인시장진흥공단 상권정보·인허가 / (수집) 네이버 플레이스 리뷰 / (기업 제공·비공개) 르몽 주문·매출·리뷰.
- **방법:** 월별 리뷰·주문·답글 피처와 재방문 추정·시계열 롤링 피처 생성, 성장 라벨링, **LightGBM·XGBoost·CatBoost 앙상블**과 랭킹 접근, 시계열 교차검증 및 데이터 누수 방지 검증.
