# STEP 4 — 01. if 문

조건문 = **참과 거짓을 판단하는 문장**. if 문 = "만약 ~라면 ~을 해라". 조건이 **참(True)이면 실행**, **거짓(False)이면 건너뜀(패스)**.

## ⭐ 핵심 규칙 2가지
- **1-1. 들여쓰기**: if에 속한 문장은 반드시 안쪽으로 밀어 씀(스페이스 2칸/4칸). 파이썬은 들여쓰기로 블록을 구분(다른 언어의 `{ }` 역할).
- **1-2. 콜론 `:`**: if 조건 뒤에 반드시 `:` 삽입. 블록 시작 신호.

---

## 1. if 문 — 조건이 참이면 실행
```python
# "Selena 수업을 들으면 파이썬을 정복할 수 있다."
selena_lecture = True

if selena_lecture:
  print("파이썬을 정복할 수 있다.")
```
**실행 결과**
```
파이썬을 정복할 수 있다.
```
- `selena_lecture`가 `True` → 조건 성립 → 들여쓰기된 print 실행.
- 만약 `False`였다면 아무것도 출력 안 하고 통과.

## 2. 들여쓰기로 여러 줄 묶기
```python
# "카페인이 첨가된 종류는 아메리카노, 카페라떼, 콜드브루가 있다."
caffeine = True

if caffeine :
  print("americano")
  print("cafe latte")
  print("cold brew coffee")
```
**실행 결과**
```
americano
cafe latte
cold brew coffee
```
같은 깊이로 들여쓴 3줄은 모두 if에 속함 → 조건 참이면 셋 다 실행.

## 자주 하는 실수
- 콜론 빠뜨림: `if caffeine` → SyntaxError (뒤에 `:` 필수).
- 들여쓰기 안 함: `if caffeine:` 다음 줄 안 밀면 IndentationError.
- 들여쓰기 칸 섞기(2칸/4칸 혼용) → 오류. 한 블록은 칸 수 통일.
- `=`(대입)와 `==`(비교) 혼동 → 조건의 "같다"는 `==`.

## 실무 팁
강의자료엔 없지만 실무에서는 조건에 단순 True/False 변수보다 **비교식**을 직접 넣는 경우가 많음: `if temperature > 38:`, `if len(data) == 0:` (데이터 비었으면 중단) 등.

## 퀴즈
1. if 조건이 거짓이면? ① 오류 ② 안쪽 실행 ③ 안쪽 건너뜀 ④ 종료
2. if 뒤 필수 기호? ① `;` ② `:` ③ `.` ④ `,`
3. 파이썬이 블록을 구분하는 법? ① `{}` ② 들여쓰기 ③ `()` ④ 따옴표
4. 코드 읽기:
```python
rain = False
if rain:
  print("우산 챙기기")
print("출발")
```
5. 코드 읽기:
```python

```
