# STEP 4 — 06. 논리연산자 (and · or · not)

**논리연산자** = 참/거짓 값을 서로 묶어 최종 판단. 관계연산자가 조건 하나를 판단했다면, 논리연산자는 그 결과들을 결합.

- **not (부정)**: 뒤집기. `not True`→False, `not False`→True
- **and (그리고)**: **둘 다 참**이어야 True
- **or (또는)**: **하나라도 참**이면 True (둘 다 거짓일 때만 False)

> 비유: and=자물쇠 2개(둘 다 풀려야 열림), or=출입구 2개(하나만 열려도 들어감), not=스위치 반전.

**진리표**

| A | B | A and B | A or B |
|---|---|---------|--------|
| T | T | T | T |
| T | F | F | T |
| F | T | F | T |
| F | F | F | F |

한 줄 요약: **and는 까다로움(다 맞아야), or는 너그러움(하나만 맞아도).**

---

## 예제
```python
# not
print(not True)      # False
print(not False)     # True

# and : 둘 다 참일 때만 True
print(True and True)     # True
print(True and False)    # False
print(False and True)    # False
print(False and False)   # False

# or : 하나라도 참이면 True
print(True or True)      # True
print(True or False)     # True
print(False or True)     # True
print(False or False)    # False
```
**실행 결과**
```
False
True
True
False
False
False
True
True
True
False
```

## 자주 하는 실수
- and/or 반대로 이해: "20살 이상 그리고 서울"=and, "서울 또는 부산"=or. 말로 먼저 정리.
- 범위 조건: "10 이상 20 미만" → `10 <= x and x < 20` 또는 `10 <= x < 20`.
- `not a == b`는 `not (a == b)`. 헷갈리면 괄호로 명확히.
- 파이썬은 `&&`, `||` 안 씀 → **and / or** 단어 사용.

## 실무 팁
강의자료엔 없지만 실무: `if age >= 19 and has_id:`, `if is_weekend or is_holiday:`, `if not is_logged_in:`. 판다스 복합 필터는 `df[(df['나이']>=20) & (df['지역']=='서울')]`처럼 `&/|` 사용(나중에 배움).

## 퀴즈
1. `and`가 True가 되는 경우? ① 하나라도 참 ② 둘 다 참 ③ 둘 다 거짓 ④ 항상
2. `not False`? ① True ② False ③ 0 ④ 오류
3. `or`가 False가 되는 경우? ① 둘 다 참 ② 하나만 참 ③ 둘 다 거짓 ④ 없음
4. 코드 읽기:
```python
print(True and False)
print(True or False)
print(not True)
```
5. 코드 읽기:
```python
age = 22
has_ticket = True
print(age >= 19 and has_ticket)
```
