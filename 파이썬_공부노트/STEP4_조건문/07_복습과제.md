## 문제 1. 중첩 조건문
수업이 끝났을 때(`endOfSelenaClass`) 복습 점수(`SelfReviewScore`)에 따라 결과 출력. **조건문 안에 조건문**(중첩).

- 1) 바깥 조건문: 수업이 끝났으면 안쪽 조건문 실행 / 진행 중이면 `"Focus Class"`
- 2) 안쪽 조건문: 90 이상 `"Perfect Score"` / 50 이상 `"Half Score"` / 그 외 `"Zero Score"`

```python
endOfSelenaClass = True
SelfReviewScore = 99

if endOfSelenaClass :
  if SelfReviewScore >= 90 :
    print("Perfect Score")
  elif SelfReviewScore >= 50:
    print("Half Score")
  else :
    print("Zero Score")
else :
  print("Focus Class")
```
**실행 결과**
```
Perfect Score
```
바깥 if로 "수업 끝?"을 먼저 거르고, 통과한 경우에만 안쪽 if로 점수를 세분화. 들여쓰기 2단계가 핵심.

## 문제 2. in / not in 연산자
`'selena_class'`에 `'c'`가 포함되어 있으면 True, 아니면 False 출력.

```python
if 'c' in 'selena_class':
    print(True)
else:
    print(False)
```
**실행 결과**
```
True
```

## 문제 3. pass 키워드
`basket`(apple, strawberry, melon)에 `'orange'`가 없으면 pass.

```python
basket = ['apple', 'strawberry', 'melon']

if 'orange' not in basket:
  pass
```
**실행 결과**
```
(출력 없음)
```
조건은 참이지만 pass라 아무 동작 없이 통과. 골격만 잡아둔 형태.

## STEP4 한눈에 정리
- if / else / elif : 조건 분기 (처음 참인 블록 하나만 실행)
- in / not in : 포함 여부 검사 → True/False
- pass : 아무 일도 안 함(자리표시)
- 관계연산자 `== != < > <= >=` : 두 값 비교 → True/False
- 논리연산자 `and`(둘 다 참) / `or`(하나라도 참) / `not`(뒤집기)
- 중첩 조건문 : if 안에 if (들여쓰기 단계로 표현)
