# STEP 4 — 05. 관계연산자

**관계연산자** = 두 값을 비교하여 **참(True)/거짓(False)** 으로 판별. if 조건의 핵심 재료.

| 연산자 | 의미 | 예 (`a=3, b=1`) | 결과 |
|--------|------|------|------|
| `==` | 같다 | `a == b` | False |
| `!=` | 같지 않다 | `a != b` | True |
| `<` | 작다 | `a < b` | False |
| `>` | 크다 | `a > b` | True |
| `<=` | 작거나 같다 | `a <= b` | False |
| `>=` | 크거나 같다 | `a >= b` | True |

⚠️ **"같다"는 `==`(등호 2개)**. `=`(1개)는 대입이라 완전히 다름 — 초보자 오류 1순위.

---

## 예제
```python
a = 3
b = 1

print(a == b)
print(a != b)
print(a < b)
print(a > b)
print(a <= b)
print(a >= b)
```
**실행 결과**
```
False
True
False
True
False
True
```

## 자주 하는 실수
- `=`와 `==` 혼동: 비교는 `if a == 3:`.
- `=<`, `=>` ❌ → 올바른 표기 `<=`, `>=`(부등호 먼저).
- 문자열 비교: `"10" > "9"` → False (사전순, 첫 글자 '1' vs '9'). 숫자 비교는 `int()` 변환.
- 실수 == 비교 위험: `0.1 + 0.2 == 0.3` → False (부동소수점 오차).

## 실무 팁
강의자료엔 없지만 실무에서 조건의 핵심: `if age >= 19:`, `if price <= budget:`, `if status != "완료":`. 데이터 분석 필터링 `df[df['나이'] >= 20]`에도 그대로 사용.

## 퀴즈
1. "같다" 비교 연산자? ① `=` ② `==` ③ `!=` ④ `=>`
2. `a=3, b=1`일 때 `a != b`? ① True ② False ③ 3 ④ 오류
3. "작거나 같다" 표기? ① `=<` ② `<=` ③ `<==` ④ `≤`
4. 코드 읽기:
```python
x = 7
print(x >= 7)
print(x < 7)
```
5. 코드 읽기:
```python
a = 5
b = 5
print(a == b)
print(a != b)
```
6. 코드 작성: `score`가 60 이상이면 `"합격"`, 아니면 `"불합격"` 출력(if–else).
