# STEP 2 — 02. 자료형 › 딕셔너리 (dictionary)

딕셔너리 = **이름표(key)로 값을 찾는** 자료형. (리스트/튜플은 번호로 찾음)
사전처럼 단어(key) → 뜻(value).

- 중괄호 `{ }`로 생성
- `key : value` 쌍을 쉼표로 연결
- key는 보통 문자열, value는 아무거나(리스트도 가능)

---

## 6-1. 선언
```python
myDictionary = {
    "name" : "Selena",
    "job" : "data scientist"
}
myDictionary['name']   # 'Selena'  (key로 값 꺼내기)
myDictionary['job']    # 'data scientist'
```

## 6-2. 변경과 삭제
```python
myDictionary['grade'] = [98, 100, 88]   # 추가 (없는 key)
myDictionary['grade'] = [100, 100, 90]  # 수정 (있는 key 덮어씀)
del myDictionary['grade']               # 삭제
```
`딕셔너리[key] = 값` → key 없으면 추가, 있으면 수정.

## 6-3. 관련 함수
```python
d = {"name":"Selena", "job":"data scientist", "grade":[100,90,80]}
d.keys()        # dict_keys(['name','job','grade'])
d.values()      # dict_values(['Selena','data scientist',[100,90,80]])
d.items()       # dict_items([('name','Selena'), ...])
d.get('grade')  # [100,90,80]  (key로 값)
d.get('hobby')  # None  (없는 key여도 오류 안 남)
'name' in d     # True  (key 있는지)
'hobby' in d    # False
d.clear()       # {}  (전부 삭제)
```

## 자주 하는 실수
- 없는 key를 `[ ]`로 접근 → **KeyError**. 안전하게는 `get()` (없으면 None)
- key는 중복 불가 (같은 key 또 쓰면 덮어씀)
- 괄호 구분: 리스트 `[ ]` / 튜플 `( )` / 딕셔너리 `{ }`
- 번호로 접근 안 됨 (`d[0]`은 key 0이 없으면 오류)

## 실무 팁
"이름-값" 짝 데이터에 사용: `{'이름':'학주','나이':20}`. 웹 데이터(JSON)와 같은 구조. Pandas 표 만들 때도 자주 사용.

## 퀴즈 — `person = {'name':'학주', 'age':20}`
1. `person['name']`? ① 'name' ② '학주' ③ 20 ④ 오류
2. 틀린 설명? ① 중괄호로 만듦 ② key로 값 찾음 ③ 번호로 값 찾음 ④ 추가·삭제 가능
3. `person.get('hobby')` (없는 key)? ① KeyError ② None ③ 'hobby' ④ 빈 문자열
4. 코드 읽기: `d={'a':1,'b':2}; d['c']=3; d['a']=10` → `d`
5. 코드 읽기: `'name' in person`, `'score' in person`, `person.keys()`
6. 코드 작성: `book`에 'title':'파이썬', 'price':20000 담고 'title' 값 출력
