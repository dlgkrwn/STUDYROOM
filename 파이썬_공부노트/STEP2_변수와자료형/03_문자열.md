# STEP 2 — 02. 자료형 › 문자열 (string)

문자열 = 글자(문자)로 이루어진 자료형. 반드시 **따옴표로 감싼다**.

---

## Part 1 — 만들기 · 이스케이프 · 연산자

### 3-1. 문자열 만들기

```python
word = "hello"      # 큰따옴표
print('hello')      # 작은따옴표 (동일)
print("I'm smart")  # 큰따옴표 안에 작은따옴표는 그냥 글자
```

**이스케이프로 따옴표 넣기** — 같은 종류 따옴표를 안에 넣으려면 `\`를 붙임
```python
print('Selena는 \'파이썬 프로그래밍\' 강의를 한다.')
# → Selena는 '파이썬 프로그래밍' 강의를 한다.
```

**여러 줄 문자열** — 삼중 따옴표 `"""`
```python
sentence = """
글을 여러 줄 쓰고 싶다.
세 줄도 되고
네 줄도 되는
"""
```
Enter 누른 그대로 줄바꿈됨. 맨 위·아래에 빈 줄이 생김.

**빈 줄 제거** — 끝에 `\` 붙이기
```python
sentence = """\
글을 여러 줄 쓰고 싶다.
세 줄도 되고
네 줄도 되는\
"""
```

### 3-2. 이스케이프 문자

| 이스케이프 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 역슬래시 `\` |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |

```python
print("1\n2")    # 1 줄바꿈 2
print("3\t4")    # 3 (탭) 4
```

### 3-3. 연산자

```python
# + 연결
a = "파이썬! "; b = "프로그래밍!"
print(a+b)          # 파이썬! 프로그래밍!

# * 반복
equal = "=" * 30    # = 30개
print(equal)        # ==============================
```

숫자와 달리 문자열에서 `+`=이어붙이기, `*`=반복.

### 자주 하는 실수

- 따옴표 짝 안 맞음: `"hello'` → 오류
- 숫자 + 문자열: `"나이: " + 20` → TypeError. `str(20)`으로 변환하거나 포맷팅 사용
- `\`를 글자로 쓰려면 `\\`

### 퀴즈 (Part 1)

1. 문자열 만들기로 틀린 것? ① `"hello"` ② `'hello'` ③ `"""hello"""` ④ 따옴표 없는 `hello`
2. `\t`의 의미? ① 줄바꿈 ② 탭 ③ 따옴표 ④ 역슬래시
3. `"abc" * 3`? ① abcabcabc ② abc3 ③ 9 ④ 오류
4. 코드 읽기: `print("가"+"나"+"다")` / `print("-"*5)`
5. 코드 읽기: `print("사과\n바나나\t딸기")`
6. 코드 작성: `"Python"`과 `"공부"`를 연결해 `Python공부` 출력

## Part 2 — 인덱싱 · 슬라이싱

문자열의 각 글자는 **번호(인덱스)** 를 가짐. 이 번호로 글자를 꺼냄.

**핵심 규칙**
- 인덱스는 **0부터** 시작 (첫 글자 = 0번)
- 뒤에서부터는 **-1** 부터 (마지막 글자 = -1번)
- 공백도 한 칸을 차지함

예: `'파이썬 하루만에 끝내보자!'`
```
파(0) 이(1) 썬(2) 공백(3) 하(4) 루(5) 만(6) 에(7) 공백(8) 끝(9) 내(10) 보(11) 자(12) !(13)
```

### 인덱싱 — 문자 하나
```python
sentence = '파이썬 하루만에 끝내보자!'
print(sentence[0])    # 파  (첫 글자)
print(sentence[-1])   # !   (마지막 글자)
```

### 슬라이싱 — 범위 `[시작:끝]`
```python
print(sentence[4:8])  # 하루만에  (4,5,6,7번 — 끝 번호 8은 미포함!)
```
**규칙: 시작 이상, 끝 미만** (끝 인덱스는 포함 안 함)

### 실무 예시
```python
date = "2026-08-03"
print(date[0:4])   # 2026 (연도)
print(date[5:7])   # 08   (월)
```

### 자주 하는 실수
- 인덱스는 1이 아니라 **0**부터
- 슬라이싱 끝 번호는 **미포함** (`[4:8]`은 8 제외)
- 없는 인덱스 접근 → IndexError (단, 슬라이싱은 범위 넘어도 오류 없이 끝까지)
- 공백도 한 칸

### 퀴즈 (Part 2) — `word = "PYTHON"` (P0 Y1 T2 H3 O4 N5)
1. `word[0]`? ① P ② Y ③ PYTHON ④ 오류
2. `word[-1]`? ① P ② N ③ O ④ -1
3. `word[1:4]`? ① YTH ② YTHO ③ PYT ④ YT
4. 코드 읽기: `s="데이터분석"` → `s[0]`, `s[2]`, `s[-1]`
5. 코드 읽기: `date="2026-08-03"` → `date[0:4]`, `date[5:7]`
6. 코드 작성: `"PYTHON"`에서 슬라이싱으로 `"HON"` 출력
