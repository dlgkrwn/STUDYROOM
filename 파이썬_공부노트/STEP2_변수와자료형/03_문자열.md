# STEP 2 — 02. 자료형 › 문자열 (string)

문자열 = 글자(문자)로 이루어진 자료형. 반드시 **따옴표로 감싼다**.

---

## Part 1 — 만들기 · 이스케이프 · 연산자

### 3-1. 문자열 만들기

```python
word = "hello"      # 큰따옴표
print('hello')      # 작은따옴표 (동일)
print("I'm smart")  # 큰따옴표 안에 작은따옴표는 그냥 글자
```

**이스케이프로 따옴표 넣기** — 같은 종류 따옴표를 안에 넣으려면 `\`를 붙임
```python
print('Selena는 \'파이썬 프로그래밍\' 강의를 한다.')
# → Selena는 '파이썬 프로그래밍' 강의를 한다.
```

**여러 줄 문자열** — 삼중 따옴표 `"""`
```python
sentence = """
글을 여러 줄 쓰고 싶다.
세 줄도 되고
네 줄도 되는
"""
```
Enter 누른 그대로 줄바꿈됨. 맨 위·아래에 빈 줄이 생김.

**빈 줄 제거** — 끝에 `\` 붙이기
```python
sentence = """\
글을 여러 줄 쓰고 싶다.
세 줄도 되고
네 줄도 되는\
"""
```

### 3-2. 이스케이프 문자

| 이스케이프 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 |
| `\\` | 역슬래시 `\` |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |

```python
print("1\n2")    # 1 줄바꿈 2
print("3\t4")    # 3 (탭) 4
```

### 3-3. 연산자

```python
# + 연결
a = "파이썬! "; b = "프로그래밍!"
print(a+b)          # 파이썬! 프로그래밍!

# * 반복
equal = "=" * 30    # = 30개
print(equal)        # ==============================
```

숫자와 달리 문자열에서 `+`=이어붙이기, `*`=반복.

### 자주 하는 실수

- 따옴표 짝 안 맞음: `"hello'` → 오류
- 숫자 + 문자열: `"나이: " + 20` → TypeError. `str(20)`으로 변환하거나 포맷팅 사용
- `\`를 글자로 쓰려면 `\\`

### 퀴즈 (Part 1)

1. 문자열 만들기로 틀린 것? ① `"hello"` ② `'hello'` ③ `"""hello"""` ④ 따옴표 없는 `hello`
2. `\t`의 의미? ① 줄바꿈 ② 탭 ③ 따옴표 ④ 역슬래시
3. `"abc" * 3`? ① abcabcabc ② abc3 ③ 9 ④ 오류
4. 코드 읽기: `print("가"+"나"+"다")` / `print("-"*5)`
5. 코드 읽기: `print("사과\n바나나\t딸기")`
6. 코드 작성: `"Python"`과 `"공부"`를 연결해 `Python공부` 출력

## Part 2 — 인덱싱 · 슬라이싱

문자열의 각 글자는 **번호(인덱스)** 를 가짐. 이 번호로 글자를 꺼냄.

**핵심 규칙**
- 인덱스는 **0부터** 시작 (첫 글자 = 0번)
- 뒤에서부터는 **-1** 부터 (마지막 글자 = -1번)
- 공백도 한 칸을 차지함

예: `'파이썬 하루만에 끝내보자!'`
```
파(0) 이(1) 썬(2) 공백(3) 하(4) 루(5) 만(6) 에(7) 공백(8) 끝(9) 내(10) 보(11) 자(12) !(13)
```

### 인덱싱 — 문자 하나
```python
sentence = '파이썬 하루만에 끝내보자!'
print(sentence[0])    # 파  (첫 글자)
print(sentence[-1])   # !   (마지막 글자)
```

### 슬라이싱 — 범위 `[시작:끝]`
```python
print(sentence[4:8])  # 하루만에  (4,5,6,7번 — 끝 번호 8은 미포함!)
```
**규칙: 시작 이상, 끝 미만** (끝 인덱스는 포함 안 함)

### 실무 예시
```python
date = "2026-08-03"
print(date[0:4])   # 2026 (연도)
print(date[5:7])   # 08   (월)
```

### 자주 하는 실수
- 인덱스는 1이 아니라 **0**부터
- 슬라이싱 끝 번호는 **미포함** (`[4:8]`은 8 제외)
- 없는 인덱스 접근 → IndexError (단, 슬라이싱은 범위 넘어도 오류 없이 끝까지)
- 공백도 한 칸

### 퀴즈 (Part 2) — `word = "PYTHON"` (P0 Y1 T2 H3 O4 N5)
1. `word[0]`? ① P ② Y ③ PYTHON ④ 오류
2. `word[-1]`? ① P ② N ③ O ④ -1
3. `word[1:4]`? ① YTH ② YTHO ③ PYT ④ YT
4. 코드 읽기: `s="데이터분석"` → `s[0]`, `s[2]`, `s[-1]`
5. 코드 읽기: `date="2026-08-03"` → `date[0:4]`, `date[5:7]`
6. 코드 작성: `"PYTHON"`에서 슬라이싱으로 `"HON"` 출력

## Part 3 — 포맷팅 · 관련 함수

포맷팅 = 문자열 안 정해진 자리에 값을 채워 넣기.

### % 방식
포맷 코드: `%d`(정수) `%f`(실수) `%c`(문자1개) `%s`(문자열)
```python
print("나는 %d호선을 타고 다녀." % 6)          # 나는 6호선을 타고 다녀.
a=4; b="학교"
print("나는 %d호선을 타고 %s를 가." % (a, b))   # 나는 4호선을 타고 학교를 가.
```
값 여러 개는 `% (a, b)` 처럼 괄호로 묶어 순서대로.

### .format() 방식
```python
print("나는 {}호선을 타고 다녀.".format(6))    # {} 순서대로 채움
print("나는 {0}호선을 타고 다녀.".format(6))   # {0} 번호 지정
```

### 관련 함수
```python
s = "Selena는 샤브샤브를 좋아해"
len(s)              # 17  (길이, 공백 포함)  ← len(문자열) 형태
s.split()           # ['Selena는','샤브샤브를','좋아해']  (공백 기준 분리)
s.count('샤브')     # 2   (개수 세기)
s.replace('샤브샤브','육회')  # 새 문자열 반환 (원본 안 바뀜)

f = 'HAMburger.jpg'
f.find('.')         # 9   (위치, 못 찾으면 -1)
f.split('.')        # ['HAMburger','jpg']
f.upper()           # HAMBURGER.JPG
f.lower()           # hamburger.jpg
'.'.join('abcde')   # a.b.c.d.e  (사이사이 삽입)
```

**사용 형태 2가지**: `len(문자열)`(감싸기) vs `문자열.split()`(점 찍고 부르기=메서드)

### 실무 팁 — f-string
강의엔 없지만 실무에서 가장 많이 씀:
```python
name = "학주"
print(f"안녕, {name}님")   # 문자열 앞 f, {} 안에 변수 직접
```

### 자주 하는 실수
- `replace`/`upper`/`lower`는 **원본 안 바뀜** → 결과를 새 변수에 담아야 함
- `len`은 `문자열.len()`이 아니라 `len(문자열)`
- `find`는 못 찾으면 `-1`
- `%s`/`%d` 개수와 값 개수 일치해야 함

### 퀴즈 (Part 3)
1. `"점수: {}점".format(90)`? ① 점수: {}점 ② 점수: 90점 ③ 점수: {90}점 ④ 오류
2. `"Hello".upper()`? ① hello ② HELLO ③ Hello ④ 원본까지 바뀜
3. `len("a b c")` (공백 포함)? ① 3 ② 4 ③ 5 ④ 6
4. 코드 읽기: `s="banana"` → `s.count("a")`, `s.replace("a","o")`, `s`
5. 코드 읽기: `email="test@gmail.com"` → `email.split("@")`, `email.find("@")`
6. 코드 작성: `name="학주"`, `age=20`을 `.format()`으로 → `학주님은 20살입니다.`
