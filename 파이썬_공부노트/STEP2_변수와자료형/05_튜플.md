# STEP 2 — 02. 자료형 › 튜플 (tuple)

튜플 = **못 바꾸는 리스트**. 리스트와 거의 같지만 두 가지가 다름:
- 리스트는 `[ ]`, 튜플은 **`( )`**
- 튜플은 값을 **바꾸거나 지울 수 없음** (변경 불가능/immutable)

---

## 5-1. 생성
```python
tuple1 = (2.3,)    # 값 하나면 뒤에 쉼표(,) 필수!
float1 = (2.3)     # 쉼표 없으면 그냥 float
type(tuple1)       # tuple
type(float1)       # float

tuple2 = 1, 2, 3, 4, 5   # 괄호 생략해도 튜플
type(tuple2)             # tuple
```
⚠️ 값 하나짜리 튜플은 반드시 `(2.3,)` — 쉼표 없으면 튜플 아님.

## 5-2. 인덱싱 · 슬라이싱 (리스트와 동일)
```python
tuple1 = (9, 8, 7, 6)
tuple1[0]      # 9
tuple2 = (5, 4, 3, 2)
tuple2[1:3]    # (4, 3)  (끝 번호 미포함)
```

## 5-3. 연산자 (리스트와 동일)
```python
tuple1 = (1, 2, 3); tuple2 = (4, 5, 6)
tuple1*2 + tuple2      # (1,2,3,1,2,3,4,5,6)
len(tuple1*2 + tuple2) # 9
```

## 5-4. 변경/삭제 → 오류!
```python
t = (1, 2, 3, 4)
t[0] = 3     # ❌ TypeError (값 변경 불가)
del t[0]     # ❌ TypeError (값 삭제 불가)
```

## 자주 하는 실수
- 값 하나 튜플에서 쉼표 빠뜨림: `(2.3)`은 float, `(2.3,)`가 튜플
- 튜플 값 바꾸려다 오류 → 바꿔야 하면 리스트 사용
- 괄호 혼동: 리스트 `[ ]` / 튜플 `( )`

## 실무 팁
값이 바뀌면 안 되는 데이터에 사용: 좌표 `(위도, 경도)`, RGB `(255,0,0)`. 안전장치 + 리스트보다 약간 빠름. 함수가 여러 값 반환할 때도 튜플.

## 퀴즈
1. 틀린 설명? ① 소괄호로 만듦 ② 값을 바꿀 수 있다 ③ 인덱싱 가능 ④ 순서 있음
2. `x=(5)` → `type(x)`? ① tuple ② float ③ int ④ list
3. `t=(1,2,3)` → `t[0]=10`? ① (10,2,3) ② (10) ③ 오류 ④ None
4. 코드 읽기: `t=(10,20,30,40)` → `t[1]`, `t[1:3]`
5. 코드 읽기: `a=(1,2); b=(3,4)` → `a+b`, `len(a*3)`
6. 코드 작성: 값 100 하나인 튜플 `single` 선언 후 `type(single)` 출력
