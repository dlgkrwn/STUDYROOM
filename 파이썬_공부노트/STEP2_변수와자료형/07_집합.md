# STEP 2 — 02. 자료형 › 집합 (set)

집합 = 수학의 집합. 두 가지 특징:
- **중복 허용 안 함** (같은 값 여러 번 넣어도 하나만)
- **순서 없음(비순서)** → **인덱싱 불가** (`set[0]` 오류)

생성: `set()` 키워드, 또는 `{ }`에 값 나열.

---

## 7-1. 생성
```python
set1 = set([10, 11, 12])   # {10, 11, 12}
set2 = set("selena")       # {'s','a','e','l','n'}  ← 'e' 중복 제거, 순서 무관
```

## 7-2. 합집합 · 교집합 · 차집합
```python
set1 = {1, 2, 3, 4, 5}; set2 = {1, 3, 5, 7, 9}
set1 | set2    # 합집합 → {1,2,3,4,5,7,9}
set1 & set2    # 교집합 → {1,3,5}
set1 - set2    # 차집합 → {2,4}
set2 - set1    # 차집합 → {9,7}
```
기호: 합집합 `|`, 교집합 `&`, 차집합 `-`

## 7-3. 관련 함수
```python
set1 = {1, 2, 3, 4, 5}
set1.add(6)            # 한 개 추가 → {1,2,3,4,5,6}
set1.update([11, 13])  # 여러 개 추가 → {..., 11, 13}
set1.remove(1)         # 특정 값 제거
```

## 자주 하는 실수
- **인덱싱 불가**: `set[0]` 오류 (순서 없음)
- **빈 집합은 `set()`으로**: `{}`는 빈 딕셔너리!
- `add`=값 하나 / `update`=여러 개
- 중복 넣어도 오류 없이 무시(하나만 유지)

## 실무 팁
가장 큰 쓰임 = **중복 제거**. `set(리스트)`로 감싸면 중복 삭제.
교집합=공통 항목, 차집합=한쪽에만 있는 항목 분석에 유용.

## 퀴즈
1. `set([1,2,2,3,3,3])`? ① {1,2,2,3,3,3} ② {1,2,3} ③ [1,2,3] ④ 오류
2. 틀린 설명? ① 중복 불가 ② 순서 없음 ③ 인덱싱 가능 ④ 합집합·교집합 가능
3. `{1,2,3} & {2,3,4}`? ① {1,2,3,4} ② {2,3} ③ {1} ④ {1,4}
4. 코드 읽기: `a={1,2,3}; b={3,4,5}` → `a|b`, `a-b`
5. 코드 읽기: `s=set([10,20,30]); s.add(40); s.remove(10)` → `s`
6. 코드 작성: `[1,1,2,2,3]`의 중복 제거한 집합 만들어 출력
