# STEP 2 — 01. 변수 (variable)

## 핵심 요약

변수 = **값을 담는 상자**. 이름을 붙이고(1-1), 값을 담고(1-2, 1-3), 꺼내 본다(1-4).

## 변수가 왜 필요한가

그냥 `7`이라고만 쓰면 컴퓨터는 계산 후 버린다. **이름표가 붙은 상자**에 넣어두면 이후 그 이름만 불러 재사용할 수 있다. 이 상자가 변수다.

## 핵심 원리: `=`는 "같다"가 아니라 "담아라"

```python
A = 1   # 오른쪽 값 1을 왼쪽 상자 A에 '담아라' (대입/할당)
```

- 방향은 항상 **오른쪽 → 왼쪽**
- 그래서 `1 = A`는 오류 (값에는 이름표를 못 붙임)
- 값을 처음 담는 것 = "변수를 선언한다"

## 1-1. 변수 이름

값의 의미를 추측할 수 있게 짓기 (`x`보다 `age`).

이름 규칙:
- 영문자, 숫자, 밑줄(`_`)만 사용
- 숫자로 시작 불가 (`2age` ❌ / `age2` ✅)
- 띄어쓰기 불가 (`my age` ❌ / `my_age` ✅)
- 예약어(`print`, `if` 등) 사용 불가

## 1-2. 변수 의미

```python
a = 7   # 7을 a에 담기
A = 1   # 1을 A에 담기
```

**중요: 파이썬은 대소문자를 구분한다.** `a`와 `A`는 완전히 다른 상자.

## 1-3. 변수 선언 3가지 방법

```python
# ① 하나의 변수에 하나의 값
a = 1
b = 1

# ② 두 변수에 같은 값
a = b = 1        # 오른쪽부터: 1을 b에, 그 결과를 a에도 → 둘 다 1

# ③ 변수에 변수를 대입
a = 1
b = a            # a의 값(1)을 꺼내 복사해 b에 담음 → b도 1
```

## 1-4. 변수 출력

```python
print(a)   # a 상자의 값을 화면에 출력
print(A)
```

`print()` = 괄호 안의 값을 화면에 보여주는 함수.

**실행 결과**
```
1
1
```

## 자주 하는 실수

- 대소문자 혼동: `age`에 담고 `Age` 출력 → NameError
- 좌우 순서: `10 = age` ❌ → 항상 `상자 = 값`
- 선언 전 사용: 담기 전에 `print(score)` → 오류
- `=`(대입)와 `==`(비교) 혼동 → `==`는 조건문에서 배움

## 실무 팁

이름은 곧 문서. `a = 45000`보다 `product_price = 45000`. 여러 단어는 `snake_case`.
