# STEP 2 — 02. 자료형 › 부울 (bool)

부울 = 참/거짓 두 값만: **`True`(참)** / **`False`(거짓)**. (첫 글자 대문자!)
주로 **비교의 결과**로 나오며, 조건문(if)의 재료.

---

## 비교의 결과가 부울
```python
"selena" == "selena"   # 같니? → True
10 < 11                # → True
10 > 11                # → False
```
`==`(같니? 비교) ≠ `=`(대입). 헷갈리지 말 것.

## 8-1. 변하지 않는 참과 거짓 (Truthy/Falsy)
값이 **비어 있으면 False**, **비어 있지 않으면 True**.

```python
if "python": ...   # 비어있지 않은 문자열 → True
if []: ...         # 빈 리스트 → False
if 1: ...          # 1 → True
if 0: ...          # 0 → False

bool('')           # False  (빈 문자열)
bool([1,2,3])      # True
```

**False로 취급되는 값**: `0`, `''`, `[]`, `{}`, `()` (비어 있는 것들)
**True로 취급되는 값**: 값이 하나라도 있는 것

## 자주 하는 실수
- `True`/`False`는 **대문자 시작** (`true`/`false`는 오류)
- `=`(대입)와 `==`(비교) 혼동 → 비교는 `==`
- 숫자 `0`도 False
- `"False"`(문자열)는 비어있지 않아 오히려 **True** 취급

## 실무 팁
조건 판단의 기초. `if 장바구니:` 처럼 값 유무로 분기.
비교 연산자(`==` `!=` `<` `>` `<=` `>=`)의 결과가 모두 부울 → 조건문·필터링 핵심.

## 퀴즈
1. `10 == 10`? ① True ② False ③ 10 ④ "True"
2. False로 취급되는 값? ① "hello" ② [1,2] ③ 0 ④ 1
3. `=`와 `==` 차이? ① 둘 다 같음 ② =대입/==비교 ③ =비교/==대입 ④ 차이 없음
4. 코드 읽기: `bool("")`, `bool("파이썬")`, `bool(0)`, `bool([1])`
5. 코드 읽기: `if []: print("A") else: print("B")`
6. 코드 작성: `x=7`이 5보다 큰지 비교 결과 출력
