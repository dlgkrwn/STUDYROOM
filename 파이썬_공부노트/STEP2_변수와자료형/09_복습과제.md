# STEP 2 — 자기주도 복습 과제 (14문제)

지금까지 배운 자료형(문자열·리스트·튜플·딕셔너리·집합)만으로 풀 수 있는 문제.
> 풀이는 아래 "정답" 섹션 참고 (스스로 먼저 풀어보기!)

---

## 1. 문자열 출력
1) 이스케이프 문자로 `파이썬 '자료형' 완벽 정복!` 출력 (작은따옴표만 사용)
2) 반복 연산자로 아래 출력 (`*` 20개)
```
********************
파이썬 '자료형' 정복
********************
```

## 2. 문자열 인덱싱/슬라이싱 — `sentence = '파이썬 하루만에 끝내보자!'`
1) `'하'` 한 글자 출력
2) `'끝내보자'` 출력 (슬라이싱)

## 3. 문자열 포맷팅 — 결과 `9 x 9 = 81`
1) `%` 연산자로
2) `.format()` 으로

## 4. 문자열 관련 함수
1) `sentence = "운동 : 풋살 승마 골프"` 에서 `'골프'`→`'수영'` 바꿔 출력
2) `sentence = "PyThon"` 소문자로 출력

## 5. 리스트 인덱싱 — `myList = [2024, 3, 9*9, ['풋살', ['승마', '수영']]]`
1) `3` 출력
2) `'승마'` 출력
3) `'수영'`에서 `'영'` 출력

## 6. 리스트 변경/삭제 — `myList = [2024, 3, 9*9, ['풋살', ['승마', '수영']]]`
1) `'풋살'`→`'야구'` 바꿔 출력
2) `'야구'` 삭제

## 7. 리스트 관련 함수 — `myList = [2024, 3, 9*9, ['풋살', ['승마', '수영']]]`
1) 3번째 위치에 `"삽입"` 삽입

## 8. 튜플 슬라이싱 — `myTuple = (1,2,3,4,5)`
1) 인덱스 2~3 출력 (결과 `(3, 4)`)

## 9. 튜플 연산자 — `myTuple1=(1,2,3)`, `myTuple2=(4,5,6)`
1) `(1, 2, 3, 1, 2, 3, 1, 2, 3, 4, 5, 6, 4, 5, 6)` 출력

## 10. 딕셔너리 선언
1) `{'name':(영어이름), 'hobby':'soccer'}` 선언·출력

## 11. 딕셔너리 변경/삭제 (10번 이어서)
1) key `'grade'`, value `[90,100,80]` 추가
2) `'grade'` → `[100,100,90]` 수정
3) `'grade'` 삭제

## 12. 딕셔너리 관련 함수
1) 함수로 key,value 쌍 얻기
2) key에 `'job'` 있는지 조사

## 13. 집합 선언
1) `[1,2,3,4]` → `mySet1`
2) `[2,4,6,8]` → `mySet2`

## 14. 집합 연산 (13번 이어서)
1) 합집합
2) 교집합
3) 차집합
