# STEP 2 — 02. 자료형 › 리스트 (list)

리스트 = 여러 값을 **순서대로 담는 상자**. 대괄호 `[ ]`로 만들고 쉼표로 구분. 안의 값 하나하나 = **요소(element)**.

특징: 여러 종류 혼합 가능 / 리스트 안에 리스트(중첩) 가능 / 인덱스 0부터.

---

## Part 1 — 선언 · 인덱싱/슬라이싱 · 연산자

### 4-1. 선언
```python
myList = [1, 1.25, 1, 'word', [1, 2, [3,4]]]
# 숫자·문자열·리스트까지 섞임. 리스트 안 리스트 = 중첩 리스트
```

### 4-2. 인덱싱 · 슬라이싱
```python
myList[0]        # 1  (0번 요소)
myList[4][2]     # [3, 4]     ← 중첩: 왼→오로 한 겹씩
myList[4][2][0]  # 3
myList[2:4]      # [1, 'word'] (2,3번 / 4번 미포함)
myList[3][0]     # 'w'  (문자열 요소의 0번 글자)
```

**종합 예제** (이해하면 정복)
```python
#         0   1    2      3-0    3-1     3-2-0     3-2-1
myList = [1, 5.2, 2*3, ['커피', '물', ['매실차', '유자차']]]
myList[3][2][0][:2]   # '매실'
# myList[3]=['커피','물',['매실차','유자차']]
# [3][2]=['매실차','유자차'] → [3][2][0]='매실차' → [:2]='매실'
```
중첩은 **대괄호를 왼쪽부터 한 겹씩** 벗겨서 읽는다.

### 4-3. 연산자
```python
list1 = [1, 2, 3]; list2 = [4, 5, 6]
list1*2 + list2         # [1,2,3,1,2,3,4,5,6]  (*반복, +연결)
len(list1*2 + list2)    # 9  (요소 개수)
```

### 자주 하는 실수
- 중첩 인덱스는 **왼→오** 순서로 (오른쪽부터 읽으면 틀림)
- 인덱스 0부터 (`[1]`은 두 번째 요소)
- 슬라이싱 끝 번호 미포함
- 없는 인덱스 → IndexError

### 실무 팁
데이터 분석에서 가장 많이 쓰는 자료형. 점수·이름 목록 등을 묶어 반복문으로 처리. Pandas 표의 바탕.

### 퀴즈 (Part 1) — `data = [10, 20, ['a','b'], 30]`
1. `data[1]`? ① 10 ② 20 ③ ['a','b'] ④ 30
2. `data[2][1]`? ① 'a' ② 'b' ③ ['a','b'] ④ 오류
3. `len(data)`? ① 3 ② 4 ③ 5 ④ 6
4. 코드 읽기: `nums=[1,2,3]` → `nums*2`, `nums+[4,5]`
5. 코드 읽기: `x=[100,['파이썬','자바'],200]` → `x[1][0]`, `x[1][0][:2]`
6. 코드 작성: `fruits`에 '사과','바나나','포도' 담고 두 번째 요소 출력

## Part 2 — 변경/삭제 · 관련 함수

리스트 핵심 특징: **값을 바꿀 수 있음(변경 가능/mutable)**. 문자열과 반대. (튜플은 못 바꿈)

### 4-4. 변경과 삭제
```python
myList[3] = "변경"    # 3번 요소를 새 값으로 덮어씀
del myList[3]         # 3번 요소를 삭제 (del = 삭제 명령)
```

### 4-5. 관련 함수 — `myList = [1, 5.2, 2, 6, 2]`
```python
myList.sort()          # 오름차순 정렬 → [1, 2, 2, 5.2, 6]
myList.reverse()       # 뒤집기 → [6, 5.2, 2, 2, 1]
myList.append(1)       # 맨 끝에 추가
myList.append([1,2])   # 리스트를 '하나의 요소'로 추가 → [..., [1,2]]
myList.extend([3,4])   # 요소를 풀어서 더함 → [..., 3, 4]
myList.insert(2,"삽입") # 2번 위치에 삽입
myList.remove(2)       # 첫 번째 2 삭제 (값 기준)
x = myList.pop()       # 맨 끝 요소 빼내고(반환) 삭제
x = myList.pop(1)      # 1번 요소 빼내고 삭제
myList.count(1)        # 1의 개수
```

**꼭 구분:**
- `append([1,2])` = 통째로 한 요소(중첩) vs `extend([3,4])` = 풀어서 붙임
- `pop`은 삭제한 값을 **반환** vs `del`은 그냥 삭제
- `remove(x)` = 값 기준 / `del`·`pop(i)` = 위치(인덱스) 기준

### 자주 하는 실수
- **`sort()`/`reverse()`는 원본을 직접 바꿈** → `myList = myList.sort()` 하면 None 담김! 그냥 `myList.sort()`
- `append`에 리스트 넣으면 중첩됨 (풀려면 `extend`)
- `remove`는 첫 번째 하나만 삭제

### 실무 팁
`result = []` 만들고 반복문에서 `result.append(값)`으로 결과 쌓기 — 매우 자주 쓰는 패턴.

### 퀴즈 (Part 2)
1. `nums=[3,1,2]` → `nums.sort()` 후 nums? ① [3,1,2] ② [1,2,3] ③ [3,2,1] ④ None
2. `a=[1,2]` → `a.append([3,4])` 후 a? ① [1,2,3,4] ② [1,2,[3,4]] ③ [[3,4],1,2] ④ 오류
3. `x=[10,20,30]` → `x.pop()` 반환값? ① 10 ② 20 ③ 30 ④ None
4. 코드 읽기: `a=[1,2]; b=[3,4]; a.extend(b)` → `a`
5. 코드 읽기: `nums=[5,3,8,3]; nums.remove(3)` → `nums`, `nums.count(3)`
6. 코드 작성: `scores=[]`에 append로 90, 85 추가 후 출력
