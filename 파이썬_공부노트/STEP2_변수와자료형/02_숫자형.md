# STEP 2 — 02. 자료형 › 숫자형 (number)

## 자료형(data type)이란

프로그램에서 표현하고 저장하는 **데이터의 유형**. 변수(상자)에 담기는 값의 종류(숫자·문자열·리스트 등). STEP2 전체가 이 자료형들을 하나씩 배우는 과정.

## 숫자형의 종류

- **정수(int)** : 소수점 없는 숫자 (`3`, `-7`, `0`)
- **실수(float)** : 소수점 있는 숫자 (`-3.2`, `3.14`). 부동 소수점이라고도 함

```python
print(3)       # 3
print(-3.2)    # -3.2
```

## type() — 자료형 확인

```python
print(type(3))      # <class 'int'>
print(type(-3.2))   # <class 'float'>
```

`int` = 정수, `float` = 실수.

## 연산자

변수: `a = 4`, `b = 3.2`, `c = 2`

| 연산자 | 의미 | 예 | 결과 |
|--------|------|-----|------|
| `+` | 덧셈 | `a+b` | 7.2 |
| `-` | 뺄셈 | `a-b` | 0.7999999999999998 |
| `*` | 곱셈 | `a*b` | 12.8 |
| `/` | 나눗셈 | `a/b` | 1.25 |
| `/` | 나눗셈 | `a/c` | 2.0 (항상 실수!) |
| `%` | 나머지 | `a%c` | 0 |
| `//` | 몫 | `a//c` | 2 |
| `**` | 제곱 | `a**c` | 16 |

## 관련 함수 (내장 함수)

```python
print(int(6.2))    # 6  (소수점 버림, 반올림 아님)
print(int(-6.2))   # -6
print(float(5))    # 5.0
print(abs(-6.2))   # 6.2  (절대값)
print(pow(4,2))    # 16   (4의 2제곱, 4**2와 동일)
```

- `int()` : 정수 변환 (소수점 이하 버림)
- `float()` : 실수 변환
- `abs()` : 절대값
- `pow(a,b)` : a의 b제곱

## 자주 하는 실수

- `/`는 항상 float 반환 → `4/2`는 `2`가 아니라 `2.0`. 정수 몫은 `//`
- 실수 오차: `a-b`가 `0.8`이 아니라 `0.7999999999999998` → 2진수 저장 방식 때문. 버그 아님
- `int()`는 반올림이 아니라 버림 → `int(6.9)` = 6
- `**`(제곱) ≠ `*`(곱셈)

## 실무 팁

- 짝수/홀수: `n % 2 == 0`
- 시간 변환 등에 `//`와 `%`를 함께 사용
- `type()`은 디버깅 시 변수 내용 확인에 유용
