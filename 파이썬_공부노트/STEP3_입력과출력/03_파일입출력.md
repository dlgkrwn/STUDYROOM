# STEP 3 — 03. 파일 입출력

파일 처리 4단계: **열기(open) → 쓰기(write) → 닫기(close) → 읽기(read)**
공책을 펼치고 → 쓰고 → 덮는 것과 같음. 다 쓰면 반드시 닫기.

**열기 모드**: `"w"`=쓰기 / `"r"`=읽기 / (`"a"`=이어쓰기, 강의 밖)

---

## 1. 열기 (open)
```python
myFile = open("python.txt", "w")   # open(경로, 모드) → 파일 객체 반환
```

## 2·3. 쓰기(write)·닫기(close)
```python
myFile = open("python.txt", "w")   # 열기
myFile.write("Programming!")       # 쓰기
myFile.close()                     # 닫기 (저장 확정)
```

## 4. 읽기 (read)
```python
# 2줄 파일 만들기
myFile = open("Python_read.txt", "w")
myFile.write("Programming! \n Hello")   # \n으로 두 줄
myFile.close()

read_file = open("Python_read.txt", "r")   # 읽기 모드

read_file.readline()    # 한 줄만 읽기 (다시 부르면 다음 줄)
read_file.readlines()   # 모든 줄을 리스트로 → ['Programming! \n', ' Hello']
read_file.readline().strip()   # \n·공백 제거
```

- `readline()` : 한 줄씩 (읽는 위치가 한 줄씩 내려감)
- `readlines()` : 전체를 리스트로
- `strip()` : 끝의 `\n`·공백 제거 (안 하면 print 시 빈 줄 생김)

## ⭐ 실무 — with 문
```python
with open("python.txt", "w") as f:
    f.write("Hello")
# 블록 끝나면 자동으로 close (안전)
```

## 자주 하는 실수
- `close()` 안 하면 저장 안 될 수 있음 → 닫기 or `with`
- `"w"`는 기존 내용 **덮어씀(삭제)** → 이어쓰기는 `"a"`
- 없는 파일 `"r"`로 열기 → FileNotFoundError
- `readline()` 결과엔 `\n` 붙어옴 → 필요시 `strip()`

## 퀴즈
1. 쓰기 모드로 열기? ① open("a.txt","r") ② open("a.txt","w") ③ write("a.txt") ④ read("a.txt")
2. 다 쓴 후 반드시 호출? ① open() ② write() ③ close() ④ strip()
3. `readlines()` 반환? ① 첫 줄 ② 모든 줄 리스트 ③ 숫자 ④ 파일 객체
4. 코드 읽기(test.txt="Hello\n"): `f.readline()` 후 `line.strip()` 출력
5. 빈칸: `myFile.__("안녕")`(쓰기), `myFile.__()`(닫기)
6. 코드 작성: "memo.txt" 쓰기 모드로 "파이썬 공부" 쓰고 닫기
