# STEP 3 — 02. 출력 (print)

`print()` = 값을 화면에 출력. 여러 값을 함께 출력하는 3가지 방법.

---

## 1-1. 큰따옴표와 더하기
```python
print("파이썬 " "프로그래밍 " "수업")    # 문자열 나란히 → 자동 연결
print("파이썬 "+"프로그래밍 "+"수업")    # + 연결 (사이 공백 없음)
```

## 1-2. 콤마
```python
print("파이썬", "프로그래밍", "수업")    # 콤마 → 사이에 공백 자동 삽입
```
→ 셋 다 결과 `파이썬 프로그래밍 수업`

## ⭐ 콤마 방식의 장점 (실무)
서로 다른 자료형도 함께 출력 가능:
```python
age = 20
print("나이:", age, "살")     # 문자열+숫자+문자열 OK
```
반면 `+`는 `"나이:" + 20` → 오류 (str 변환 필요).

## 세 방법 비교
| 방법 | 사이 공백 | 다른 자료형 |
|------|-----------|-------------|
| 나란히 | 없음 | 문자열만 |
| `+` | 없음 | 같은 자료형만 |
| 콤마 `,` | 자동 1칸 | 가능(추천) |

## 자주 하는 실수
- `+`로 문자열+숫자 → 오류. 콤마 쓰거나 `str()` 변환
- 콤마는 공백 자동 삽입 / `+`는 안 넣음 → 간격 주의
- 문자열 나란히 자동연결은 따옴표 문자열끼리만 (변수엔 안 됨)

## 퀴즈
1. `print("A","B","C")`? ① ABC ② A B C ③ A,B,C ④ "A" "B" "C"
2. 콤마 출력 시 값 사이? ① 없음 ② 공백 1칸 ③ 콤마 ④ 줄바꿈
3. `print("점수: " + 90)`? ① 점수: 90 ② 점수: ③ 오류 ④ 90
4. 코드 읽기: `print("파이썬"+"최고")`, `print("파이썬","최고")`
5. 코드 읽기: `name="학주"; age=20` → `print(name,"님은",age,"살")`
6. 코드 작성: 콤마로 `이름: 학주 나이: 20` 출력
