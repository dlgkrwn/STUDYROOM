# STEP 3 — 01. 입력 (input)

`input()` = 사용자에게 값을 입력받는 함수. 괄호 안 안내 문구 = **프롬프트 문자열**.

## ⭐ 핵심 규칙
**`input()`의 결과는 무조건 문자열(str)!** 숫자를 입력해도 `"7"`(문자열)로 받음.

---

## 1. 사용자 입력 받기
```python
name = input("이름을 적어주세요. : ")
type(name)      # str

number = input("숫자 입력 : ")
type(number)    # 숫자 넣어도 str
```

## 2. 숫자로 변환 — int(), float()
```python
string1 = input()   # "1"
int1 = int(string1) # 1
string2 = input()   # "2"
int2 = int(string2) # 2

print(string1 + string2)   # "12"  (문자열 연결)
print(int1 + int2)         # 3     (숫자 덧셈)
```
같은 1, 2라도: 문자열 `+` = 이어붙이기, int 변환 후 `+` = 덧셈.

## 3. 문자열로 변환 — str()
```python
int1 = 123
str1 = str(int1)    # "123"
type(str1)          # str
```

## 자주 하는 실수
- input 결과로 바로 계산하면 문자열 연결됨 → `int()` 변환 필수
- `int("abc")` → ValueError (숫자 형태 문자열만)
- `"나이: " + 20` → 오류 → `"나이: " + str(20)`

## 실무 팁
input, 웹 폼, 파일에서 읽은 값은 대부분 문자열 → 계산 전 `int()`/`float()` 변환 습관.

## 퀴즈
1. `age=input()`에 20 입력 → `type(age)`? ① int ② float ③ str ④ bool
2. input 괄호 안 안내 문구 명칭? ① 변수 ② 프롬프트 문자열 ③ 인덱스 ④ 이스케이프
3. `"5"`를 정수로? ① str() ② float() ③ int() ④ input()
4. 코드 읽기(3,4 입력): `a=input(); b=input()` → `a+b`, `int(a)+int(b)`
5. 코드 읽기: `num=100; result=str(num)` → `result+"점"`
