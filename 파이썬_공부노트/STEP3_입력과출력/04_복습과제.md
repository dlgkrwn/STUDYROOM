# STEP 3 — 자기주도 복습 과제 (3문제)

input, 파일 입출력만으로 풀 수 있는 문제.
> 스스로 먼저 풀어보기! 풀이는 아래 "정답" 참고.

---

## 1. 사용자 입력
1) `input()`으로 `int_7`에 숫자 `7` 입력받아 저장
2) `int_7` 타입 출력
3) `int_7`을 숫자로 변환하여 저장
4) `int_7` 타입 출력

## 2. 파일 입출력 — 쓰기
1) `'inputOutput.txt'`를 쓰기 모드로 열어 `myFile`에 저장
2) `myFile`에 `"Input! \n Output!"` 쓰기
3) `myFile` 닫기

## 3. 파일 입출력 — 읽기
1) `inputOutput.txt`를 읽기 모드로 `read_file`에 저장
2) 한 줄씩 읽는 함수 + `strip()`으로 줄바꿈 제거하여 출력

---

## 정답

```python
# 1. 사용자 입력
int_7 = input("숫자 7 입력해주세요. : ")
print(type(int_7))     # <class 'str'>  ← input은 무조건 문자열
int_7 = int(int_7)     # 숫자로 변환
print(type(int_7))     # <class 'int'>

# 2. 파일 쓰기
myFile = open("inputOutput.txt", "w")
myFile.write("Input! \n Output!")
myFile.close()

# 3. 파일 읽기
read_file = open("inputOutput.txt", "r")
print(read_file.readline().strip())   # Input!  (한 번 더 실행하면 Output!)
```

### 핵심 포인트
- 1번: `input()` 결과는 `str` → `int()`로 변환해야 숫자
- 2번: 열기(open "w") → 쓰기(write) → 닫기(close)
- 3번: `readline()`은 한 줄씩(다시 부르면 다음 줄), `strip()`으로 `\n` 제거
