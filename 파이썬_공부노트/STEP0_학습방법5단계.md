# STEP 0 — 학습 방법 5단계

## 핵심 요약

이 강좌를 효과적으로 공부하는 5단계 방법. 강좌는 **구글 코랩(Google Colab)** 위에서 진행된다. 코랩은 내 컴퓨터에 파이썬을 설치하지 않아도 크롬 브라우저만으로 파이썬을 쓰고 실행하는 도구다.

## 5단계

1. **수업 준비**
   - 크롬으로 구글 로그인 → 구글 드라이브에서 코랩 연결 확인 (없으면 '연결할 앱 더보기'에서 설치)
   - 실습용 코랩 파일 열고 → `파일 > 드라이브에 사본 저장` (원본 보존, 사본에 실습)
   - 화면 분할: 한쪽 강의, 한쪽 코랩
   - 이어서 공부할 땐 왼쪽 '목차' 탭 활용

2. **실시간 타이핑 실습**
   - 정답지 파일(코드 완성본, 오류 시 참고) / 실습 파일(빈 코드, 직접 입력)
   - 강의를 멈추고 **직접 손으로 타이핑**하는 게 핵심

3. **바로 복습**
   - `수정 > 모든 출력 지우기` 후, 코드 한 줄씩 결과를 예상하고 실행해 맞춰보기

4. **나만의 강의노트 만들기**
   - 코랩의 `+코드`, `+텍스트` 버튼으로 셀 추가해 내용 정리

5. **Q&A 활용**
   - 이해 안 되는 부분, 복습하며 어려운 부분 질문으로 해결

## 자주 하는 실수

- 원본 파일에 바로 실습 → 반드시 '사본 저장' 후 실습
- 눈으로만 보고 넘어가기 → 반드시 직접 타이핑
