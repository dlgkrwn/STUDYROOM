# STEP 1 — 파이썬 시작 (파이썬 기본 다지기)

## 핵심 요약

파이썬이 무엇이고, 왜 배우며, 어디에 쓰이고, 어떤 도구로 코딩하는지 전체 그림을 잡는 단계. (코드 없음, 개념 소개)

## Python Programming의 의미

- **Python** = 인간이 컴퓨터에 명령을 내리기 위한 프로그래밍 언어 (컴퓨터와 대화하는 언어)
- **Programming** = 내가 생각한 것을 컴퓨터에 명령하는 것 (= '개발')
- **Python Programming** = 파이썬으로 컴퓨터에 명령을 내리는 행위

## 파이썬 소개 & 장점

- 가장 인기 있고 쉬운 언어 (TIOBE 인기 순위 1위)
- 장점 3가지
  1. **간결·직관적 문법** — Java로 10줄 짤 걸 파이썬은 3줄
  2. **높은 확장성·이식성** — 다른 언어/라이브러리와 쉽게 연동
  3. **풍부한 라이브러리** — 남이 만든 기능 꾸러미(라이브러리)를 가져다 씀

## 활용 분야

인공지능(기계학습), 웹·앱(구글·인스타그램·넷플릭스·드롭박스), 게임, 핀테크·블록체인

## 에디터(Editor)

코드를 편집하는 프로그램. PyCharm(가장 많이 씀), Jupyter(웹에서 작성·실행), VS Code(MS 제작), IDLE(파이썬 기본 내장)

## Jupyter Notebook & Google Colab

- **Jupyter Notebook**: '코드 + 실행 결과 + 문서'를 한 파일에 담는 대화식 환경. 일부 코드만 골라 실행 가능
- **Google Colab** = Google Drive + Jupyter Notebook. 설치 없이 웹에서 코딩, 대부분 패키지 설치됨, 무료 GPU 제공 → **이 강좌의 도구**

## 정리

- 파이썬 = 언어, 코랩/주피터 = 그 언어를 쓰는 작업 공간
- 라이브러리는 필요할 때 하나씩 익히면 됨
