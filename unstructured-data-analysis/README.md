# 비정형 데이터 분석 (R · 웹 스크래핑 · Shiny)

웹/비정형 데이터를 수집·파싱하고 분석·시각화한 프로젝트. HTML·JSON 파싱과 R Shiny 애플리케이션 개발을 다룸.

- **분야:** 비정형 데이터 · 웹 스크래핑 · HTML/JSON 파싱 · R Shiny
- **소속:** 순천향대학교 AI·빅데이터학과
- **내 역할:** _(담당 파트 기입)_

## 내용
- **웹 스크래핑/파싱:** 영화 명대사 HTML 파싱(`code_moviequotes.txt`), 배우·영화(007) JSON 파싱(`actors_code_json.txt`, `bondmovies_code_json.txt`).
- **분석:** 아파트 가격 등 데이터 수집·전처리, 지오코딩·지도 시각화(강의/실습 기반).
- **배포:** R **Shiny** 앱으로 분석 결과 애플리케이션화.

## 폴더
- `code/` — 스크래핑·파싱 코드(R).
- `발표자료.pptx` — Shiny 앱 포함 최종 발표.

> 원본 수집 데이터(아파트 가격 rdata 등)는 용량 문제로 미포함. 코드·발표자료 중심 정리.
