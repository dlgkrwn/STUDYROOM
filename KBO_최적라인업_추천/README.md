# 추정 득점 예측 모델을 통한 팀별 최적 라인업 추천 (KBO)

KBO 야구 데이터를 분석해 **추정 득점 예측 모델로 팀별 최적 타순(라인업)을 도출**하고 기존 라인업과 비교한 데이터 분석 프로젝트.

- **분야:** 데이터 수집(크롤링) · EDA · 회귀 예측 모델링 · 세이버메트릭스
- **유형:** 데이터톤 (Tech!t Data Analysis School, 팀 "퍼펙트게임", 6인) · 2024.06
- **내 역할:** **KIA 데이터 수집·전처리, 관련 연구 조사, 검증 작업, 모델링**

## 배경 · 목표
- 코칭스태프의 직관에 의존하던 기존 타순 결정 방식의 한계 → **데이터 기반 타순 결정**의 필요성.
- 데이터 분석으로 최적의 타순을 도출해 팀 경기 승률을 높이고, 야구팬의 데이터 기반 야구 분석에 대한 이해를 높이는 것을 목표로 함.

## 데이터
- **KBO 10개 구단, 2019 ~ 2024.6.24** 선수·팀 성적(타격·수비·투구·주루).
- 출처: **KBO 기록실, 스탯티즈(Statiz)** — Selenium으로 크롤링.
- 전처리 예: hitter 10경기·31타수 이상, batting_order 10타수 이상 데이터만 사용.

## 방법
`주제 선정 → 관련 연구 조사 → 데이터 수집(Selenium) → 전처리(numpy·pandas) → EDA(Matplotlib·Seaborn) → 모델링(Sklearn·Pycaret·Optuna) → 최적 라인업 도출 → 기존 라인업과 비교`

## 폴더 구조
- `크롤링 코드/` — KBO·스탯티즈 크롤링 노트북.
- `검토사항/` — EDA·상관분석 등 검토 노트북.
- `추정 득점 예측 모델링/` — 모델 선택·최적 파라미터 노트북.
- `팀별 라인업/` — 10개 구단별 라인업 분석 노트북.
- `data/` — 구단·연도별 성적 CSV (공개 데이터).
- `발표자료.pdf`, `보고서.pdf`

## 기술 스택
`Python` `Selenium` `pandas` `numpy` `Matplotlib` `Seaborn` `scikit-learn` `PyCaret` `Optuna`
