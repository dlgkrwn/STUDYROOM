# KBO 팀 추천 시스템

야구를 잘 모르거나 응원 팀을 바꾸고 싶은 사용자를 위해, **키워드 선택만으로 성향에 맞는 KBO 팀 상위 3개를 추천**하는 시스템.

- **분야:** 데이터 분석 · 추천(스코어링 기반) · 시각화(R Shiny) · 세이버메트릭스
- **팀:** 4인 (송정훈, 문가빈, 이학주, 이윤지)
- **내 역할:** 데이터 전처리·EDA·모델링(스코어링 로직) 등 전 과정 참여

## 배경
- 코로나 이후 KBO 관중 수가 매년 증가하며 대중의 관심이 늘었으나, 야구를 잘 모르는 사람은 응원 팀 선택에 어려움을 겪음.
- 사용자가 키워드를 직접 선택하면 성향에 맞는 팀을 추천해 주는 서비스로 이 문제를 해결.

## 방법 — 키워드별 점수 부여 → Top 3 추천
5개 키워드에 대해 사용자의 선택에 따라 해당 팀에 점수를 부여하고, 총점이 높은 상위 3개 팀을 추천한다.
1. **지역(연고지)** — 선택 지역의 연고 팀에 가점
2. **우승팀** — 사용자가 설정한 최근 n년 우승 빈도
3. **선수 능력치** — 포지션·유형(타격/수비/투구)·지표별 상위 선수의 소속 팀에 가점
4. **선수 유명세** — 인기 순위 상위 선수의 팀에 가점
5. **팀 성향** — 공격형/수비형 선택에 따라 해당 팀에 가점

## 데이터 · 전처리
- **팀 성적(10년, 2014~2023)**, **선수 성적(5년, 2018~2023)** — 타격·수비·투구.
- 세이버메트릭스 지표 활용: `AVG` `OPS` `WAR` `wRC+` `ERA+` `WPA` `RNG` `ARM` 등.
- 전처리: 결측값 0 처리, object→float 형변환, 타석·이닝 하위 이상치 제거, 상관분석으로 유의 변수 추출, 포지션별 TOP5 도출.

## 구현
- **Python** — 키워드 입력 기반 팀 점수 계산 및 Top 3 추천 로직.
- **R Shiny** — 선수 능력치·팀 경기성향 시각화.
