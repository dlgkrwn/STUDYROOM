# 레시피 데이터 한국어 NLP 프로젝트

한국어 레시피 검색 데이터를 대상으로 **형태소 분석 기반 텍스트 처리와 예측 모델링**을 수행한 자연어처리 프로젝트.

- **분야:** NLP(한국어) · 텍스트 전처리 · 회귀 모델링
- **소속:** 순천향대학교 AI·빅데이터학과
- **내 역할:** _(팀/개인 여부와 담당 파트 기입)_

## 내용
- 데이터: 레시피 검색 데이터(`TB_RECIPE_SEARCH`) — 요리명·상황·재료·종류 등.
- 전처리: **KoNLPy Okt** 형태소 분석, 텍스트 정제/토큰화.
- 모델: scikit-learn 기반 특징 스케일링 + **MLPRegressor** 등으로 예측.
- 환경: Google Colab (Mecab/KoNLPy 설치 포함).
